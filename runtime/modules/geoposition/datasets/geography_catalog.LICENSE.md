# Geography catalog data

`geography_catalog.json` is generated from the ISO 3166-1 and ISO 3166-2
datasets distributed by the Debian `iso-codes` project.

- Project: https://salsa.debian.org/iso-codes-team/iso-codes
- License: LGPL-2.1-or-later
- Dataphyre generator:
  `runtime/modules/geoposition/tooling/build_geography_catalog.mjs`

The generated catalog is kept separate from Dataphyre's MIT-licensed source
code so its data provenance and license remain explicit.
